## What we do

Senior backend engineers who can take a feature from sketch to production —
including API design, data modeling, security review, and deployment.

## Typical projects

- Greenfield service in Go or Python (8–12 weeks)
- gRPC / GraphQL gateway in front of an existing monolith
- Event-driven architecture with Kafka / NATS / RabbitMQ
- Multi-tenant SaaS hardening (isolation, quotas, billing integration)

## Tech we love

- **Go** for high-throughput APIs and infrastructure tooling
- **Python** for data pipelines and ML backends
- **TypeScript** for BFFs and internal tools
- **Postgres** as the boring, reliable default
- **Kafka / NATS** for async work that doesn't fit the request/response model
